# SDD Finanzas

Pequeña PWA local-first para gestión de finanzas personales (transacciones, ahorros, metas, límites y backups cifrados).

Desarrollo:
- Inicio: npm install && npm run dev
- Tests: npm test

Funcionalidades principales:
- Transacciones (CRUD)
- Ahorros: metas y artículos
- Límites por periodo y alertas
- Import/Export (CSV/JSON, XLSX opcional)
- Backups encriptados y backups automáticos

Ver HANDOFF.md para detalles de despliegue y mantenimiento.
